# Kirtika Birthday Surprise

Updated pink pastel birthday website.

## What's included
- `index.html`: home page, Polaroid photo gallery, animated envelope letter, floating hearts/sparkles, interactive cake and mystery gift.
- `countdown.html`: separate live countdown page.
- `style.css`: shared responsive styling.
- `script.js`: music and interactions.
- `countdown.js`: live countdown to **23 November 2026, 12:00 AM IST**.

## Keep your existing photos and MP3
The ZIP cannot contain the photos/music stored only on your computer. After extracting this update, copy your existing media from your old project into:
- `assets/images/photo1.jpg`
- `assets/images/photo2.jpg`
- `assets/images/photo3.jpg`
- `assets/music/birthday-music.mp3`

Use exactly these filenames. Keep the real `.jpg` and `.mp3` extensions.

## Run it
Open `index.html` in Chrome or Edge. Use the Countdown link in the top navigation. Music starts only after the visitor clicks Play music because browsers block autoplay with sound.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `birthday-surprise`.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for the Pages URL to appear.

GitHub Pages on GitHub Free requires a public repository. Anything committed there, including photos and messages, is publicly accessible. Only upload photos and music you are comfortable sharing publicly and have permission to use.
